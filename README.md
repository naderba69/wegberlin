## التشغيل والفحص

```bash
npm ci
npm run dev -- --hostname 0.0.0.0
```

ثم افتح المنصة من عنوان الخادم أو معاينة Arena. الإعدادات تحفظ البيانات في جهاز المتعلّم ولا تعتمد على filesystem أو قاعدة بيانات سحابية.

```bash
npm run check
npm run test:e2e
```

`check` يشغّل Lint وTypeScript وVitest والأسرار وحداثة المصادر وHandoff وبناء Production. `prebuild` يتحقق من تقارير المحتوى الحالية، ثم **lesson:quality:audit** و**learning:integrity:audit** يعيدان الحساب من المصدر ويمنعان تقريرًا قديمًا أو عدادات محررة يدويًا. تعريف المقاييس وحالة legacy في ADR-100؛ الأسئلة المقيدة ذات الجواب الواحد ليست مصحح كتابة حرة.

بعد تغيير المحتوى، أعد توليد تقاريره بالأوامر `*:write` المناسبة، ولا تغير رقمًا في JSON لإجبار النجاح. `repair-lesson-feedback.ts` عملية تأليف يدوية التشغيل، وليست إصلاحًا صامتًا أثناء البناء.
