# Der Weg nach Berlin — الطريق إلى برلين

منصة تعلم ألمانية عربية **Guidance-first** من A1 إلى B2. الصفحة الأساسية ليست فهرس دروس، بل مدرب يومي يختار المهمة التالية ويشرح سببها ومعيار نجاحها.

## الحالة الحالية

هذه النسخة تتضمن المنهج الأكاديمي الموجّه كاملًا من A1 إلى B2 بعدد 84 درسًا و30 مراجعة/مشروعًا وأربع بوابات داخلية، إضافة إلى 24 تدريب امتحان موجّهًا، وست محاكاة كاملة أصلية لكل من Goethe وtelc، ومكتبة من 160 مادة. راجع `PROJECT_STATUS.md` للأعداد الصريحة والقيود الصادقة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## فحص الجودة

```bash
npm run check
```

يشغل lint وTypeScript وVitest و`source:audit --strict` و`handoff:check` وProduction build. تشغّل `prebuild` فهرس Offline ثم `content:audit` وتفشل إذا خالف كائن أكاديمي Zod أو ظهر تسريب غير معتمد أو تقادم تقرير التغطية. يفشل فحص المصادر بعد 30 يومًا دون مراجعة بشرية، ويتحقق `handoff:check` من برومبت الاستمرار وأعداد P0/P1/P2 والصوت والمصادر وتقارير المحتوى وOffline والـCache والاختبارات الموثقة.

## النشر

1. استخدم `wegberlin-full.zip` و`wegberlin-full.zip.sha256` مع الأمر الواحد الموثق في `TERMUX_GITHUB_UPLOAD.md`؛ السكربت يطلب PAT مخفيًا ولا يستخدم Force.
2. ارفع الاستبدال النظيف إلى `https://github.com/naderba69/wegberlin`.
3. اربطه بمشروع Vercel Hobby شخصي غير تجاري.
4. اجعل `main` فرع Production وPull Requests للـPreview.
5. لا تضف مفاتيح API إلى المستودع أو متغيرات `NEXT_PUBLIC_*`.

## البيانات

التقدم محفوظ على جهاز المتعلم في IndexedDB. لا يعتمد على filesystem الخاص بـVercel أو قاعدة بيانات بعيدة. استخدم الإعدادات لتصدير نسخة `.dwnb`.
