# ADR-017: كل جزء مختلط لغويًا يُعزل اتجاهيًا ويُوسم لغته، ببوابة DOM لا بعينة

- **التاريخ:** 2026-09-05
- **الحالة:** مقبول ومُنفَّذ
- **البند:** P0-254 (`lang=de` لكل نص ألماني و`lang=ar` للعربي)

## السياق

الواجهة كلها عربية (`<html lang="ar" dir="rtl">`)، وداخلها مئات الأجزاء الألمانية:
أسماء وحدات امتحانية، وعناوين مصادر رسمية، ومصطلحات نحوية مدمجة **داخل جمل عربية
مؤلفة** (`Perfekt`، `Dativ`، `Partizip II`). مشكلتان منفصلتان:

1. **الوسم اللغوي**: بدون `lang="de"` يقرأ قارئ الشاشة الألمانية بصوت عربي. ولا
   يكفي تعديل البيانات، لأن المحتوى المؤلف يضع المصطلح في وسط الجملة العربية —
   وإدخال HTML داخل النصوص المؤلفة مرفوض (انظر ADR-008).
2. **العزل الاتجاهي**: علامات الترقيم والأرقام المحايدة بين Runs متعاكسة الاتجاه
   تختلط بلا عزل (Bidi isolation).

وكان التدقيق نفسه عينة: 93 موضعًا موسومًا يدويًا، بلا قياس على DOM الفعلي، وبلا
بوابة تمنع الانحدار.

## القرار

1. **محرّك واحد من مصدر واحد**: `src/core/a11y/bidi.ts` (`BIDI_POLICY_VERSION =
   "bidi-isolation-v1"`) يقسّم كل نص إلى Runs لاتينية وما عداها
   (`splitMixedRuns`) ويصنّف اللاتيني (`classifyLatinRun`) إلى `de` أو `en` أو
   `other`، ويعيد خطة عرض (`isolateSegments`) لا HTML. إعادة تجميع الـRuns تساوي
   النص الأصلي حرفيًا — مثبت في اختبار على 84/84 درسًا.
2. **قواعد التصنيف** (إرشاقية، معلنة الحدود):
   - الألمانية: أداة/كلمة استفهام ألمانية، أو حرف `ä/ö/ü/ß`، أو عبارة من 3 كلمات
     فأكثر، أو كلمة مفردة كبيرة الحرف الأول غير تقنية.
   - الإنجليزية: علامة إنجليزية فارقة **ولا دليل ألماني**. الغرض ألا تُوسم
     العناوين الرسمية الإنجليزية (`Terms and Conditions for Exam Administration`)
     ألمانية فتُقرأ بصوت ألماني. المشتركات الألمانية (`die These`، `er will`)
     محذوفة من القائمة قصدًا.
   - التقني والإنجليزي غير الألماني (`IndexedDB`, `Shadowing`, `Media Store`)،
     والرموز العشوائية (معرّف بناء، Base64): تُعزل اتجاهيًا بلا وسْم لغوي.
   - الرمز العشوائي يُميَّز ببنيته (رقم، أو حرفان كبيران متتاليان، داخل كلمة
     واحدة) لا بطوله، حتى لا يبتلع `Goethe-Institut` و`Zertifikat`.
   - الأرقام والشرطة السفلية جزء من الرمز: `MP3` و`A1` و`SM-2` ومعرّف البناء
     تُمسك كاملة، فلا تُبتور إلى `MP` أو `Build ZJp2` تُصنَّف ألمانية خطأً.
3. **عرض بلا HTML**: `BidiText` يرسم الخطة عناصر React (`dir="ltr"` دائمًا،
   و`lang="de"` أو `lang="en"` عند التصنيف). لا `dangerouslySetInnerHTML`.
4. **بوابة DOM، لا عينة**: `tests/e2e/bidi-audit.ts` يصدّر الأنماط كنصوص (من
   `bidi.ts` نفسه) و`bidiAuditInPage` الذي يمشي شجرة DOM ويحسب اللغة المتوقعة
   لكل Run، ثم يقارنها بأقرب `lang` وبالاتجاه المحسوب. اختبار
   `tests/e2e/critical-flows.spec.ts` يطبّقها على 22 مسارًا ويشترط أن يمسح أكثر
   من 1000 Run فعليًا، فلا يمرّ الاختبار بصفحة فارغة أو بمسح وهمي.

## النتائج المقيسة (لا تقديرات)

- قياس بوابة DOM: **2060 Run** لاتيني مصنَّف على 30 مسارًا، **0 مخالفة**؛
  والبوابة داخل الاختبار على 22 مسارًا: 0 مخالفة.
- مسار الانحدار على نفس المقياس: 780 → 119 → 102 → 85 → 63 → 21 → 0 مخالفة.
- أثر جانبي صحيح: كشف الرحلة إخفاق تباين حقيقيًا في نصوص ثانوية باهتة
  (`#919b97` على `#fffdfa` = 2.82:1 عند 8px) فصارت `#5f6b65` = 5.48:1.

## البدائل المرفوضة

- **تعديل البيانات لوسم المواضع**: يفشل أمام المصطلح المدمج في جملة عربية،
  ويدفع إلى HTML داخل المحتوى المؤلف (مرفوض في ADR-008).
- **`dir="auto"` وحده**: يحل الاتجاه البصري ولا يحل صوت قارئ الشاشة، لأن
  `lang` هو ما يختار الصوت.
- **قائمة كلمات ألمانية مغلقة**: لا معجم ألماني متاح دون اتصال (والتنزيل مقيد
  بالشبكة في مساحة العمل)، والقائمة المغلقة تسقط أمام أي محتوى جديد.

## الحدود المعلنة

التصنيف إرشاقي لا معجم ألماني؛ والكلمة المفردة الكبيرة تُفترض ألمانية لأن محتوى
المشروع كذلك. البوابة تغطي 22 مسارًا والقياس اليدوي غطّى 30، لا كل شاشة نادرة.
والجولة البشرية مع قارئ شاشة حقيقي ومتصفحات غير Chromium هي P0-255 لا هذا العنصر.
