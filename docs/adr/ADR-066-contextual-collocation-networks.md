# ADR-066 — التراكيب شبكة قرارات سياقية لا قائمة مرادفات

**الحالة:** مقبول ومطبق  
**التاريخ:** 2026-09-11  
**السياسة:** `contextual-collocation-network-v1`

## القرار

يغلق `/practice/collocations` البند P2-108 عبر 16 شبكة أصلية، أربع لكل A1/A2/B1/B2، بإجمالي 48 وصلة. كل شبكة تضع كلمة مركزية مع ثلاثة تراكيب مختلفة الوظيفة، مثل:

- `einen Termin vereinbaren / verschieben / absagen`
- `eine Entscheidung treffen / ändern / begründen`
- `Verantwortung übernehmen / tragen / teilen`
- `eine Annahme überprüfen / infrage stellen / widerlegen`

كل وصلة تملك معنى عربيًا، سياقًا ألمانيًا وعربيًا، سجلًا، مثالًا ألمانيًا ومعناه، وحدًا يشرح لماذا لا تصلح الوصلة الأخرى في الموقف نفسه.

## دورة الاستخدام

1. `Netz erkunden`: فتح الوصلات الثلاث ورؤية اختلاف المقصد.
2. `Kontext wählen`: إخفاء الخريطة واختيار الوصلة المناسبة لثلاثة سياقات German-first.
3. `Übertragen`: نتيجة محدودة ودعوة لاستعمال التركيب في درس أو كتابة فعلية.

لا يفتح الاختبار قبل استكشاف الوصلات الثلاث. وضع `guided` يعرض معنى السياق العربي، و`challenge` يؤجله حتى الالتزام. التصحيح لا يقول «مرادف خاطئ»، بل يبين أن الفعل المختار يمثل إجراءً مختلفًا.

## الحالة والخصوصية

`collocationNetworkAttempts` جزء من LearningState وZod وIndexedDB وDWNB وMerge. يحفظ معرف الشبكة، الوضع، معرفات الوصلات المستكشفة/المستهدفة/المختارة، وعدد المطابقات من ثلاثة. لا يحفظ نصًا حرًا أو المثال أو ضغطات مفاتيح، ولا ينشئ SRS تلقائيًا ولا يغير mastery أو CEFR.

المحرك `deterministic-context-match` يرفض معرفًا خارج الشبكة، استكشافًا ناقصًا، Target مكررًا، أو correctness لا يطابق IDs المصدرية. لا يوجد `fetch` أو AI، ولا تدعي الشبكات أنها تحصر كل التراكيب الألمانية الممكنة.

## Offline والاختبارات

أضيف المسار إلى الحزم الخمس، فصار السجل 306 مسارات والحزم 58/58/58/219/318، وارتفعت Cache المتزامنة إلى `v118`.

تغطي Vitest توازن 16/48، اكتمال السياق/المثال/السجل/الحد، اختلاف الوصلات، رفض الأدلة المزورة، Zod وMerge دون mastery، وعقد UI. يغطي Playwright استكشاف الوصلات، قفل الاختبار، اختيارًا خاطئًا ثم صحيحًا، إكمال 3 سياقات، الحفظ بلا نص، وضع التحدي، B2، 320px وaxe. المراجعة اللغوية المستقلة تبقى للجولة البشرية النهائية.
