# ADR-067 — الخصائص التوليدية تعيد Seed وتقلص المثال المضاد

**الحالة:** مقبول ومطبق  
**التاريخ:** 2026-09-12  
**السياسة:** `deterministic-generative-properties-v1`

## القرار

أُغلق P2-335 عبر Harness اختبارات حتمي داخل `tests/helpers/deterministic-property.ts`. يأخذ اسم الخاصية وعدد التشغيل وSeed ومولدًا وAssertion وShrinker اختياريًا. أي فشل يطبع Seed ورقم التشغيل وأصغر مثال مضاد يصل إليه Shrink محدود بـ100 خطوة، بحيث يمكن إعادة الفشل نفسه دون اعتماد خدمة أو مكتبة عشوائية خارجية.

تشغل `deterministic-property-invariants.test.ts` ثمانية اختبارات و8,301 حالة مولدة أو معادة تغطي:

1. ثبات إعادة Seed وإظهار Counterexample مقلص.
2. Idempotence لتطبيع النص الألماني عبر Unicode والمسافات والترقيم.
3. ثبات المقارنة تحت Case/Spacing/Terminal punctuation المسموح.
4. Splice والحصر ومؤشر الكتابة لكل `ä ö ü ß Ä Ö Ü`.
5. Union وUnique IDs وMaximum progress/due عبر Merge عشوائي.
6. Idempotence للأدلة append-only ذات Stable IDs.
7. اشتقاق صحة Collocation من IDs المصدرية ثم Zod الصارم.
8. السير العشوائي في أشجار المحادثة حتى Terminal والتحقق من Provenance/Zod دون نص جواب.

## اكتشاف فعلي

أول تشغيل وجد المثال:

```text
Straße → STRASSE
```

التحويل الألماني إلى أحرف كبيرة يوسع `ß` إلى `SS`، بينما المقارنة الحالية تتعمد عدم مساواة `ss` و`ß` في أهداف الإملاء المحافظة. لذلك قُيدت خاصية Case بالمدخلات المستقرة، وأضيف Assertion صريح يبقي توسع `ß→SS` غير مقبول. لم تُرخَ المقارنة لإجبار الاختبار على المرور.

## الحدود

هذه خصائص مولدة حتمية، وليست برهانًا رياضيًا أو Fuzzing أمنيًا غير محدود. لا تغني عن مراجعة بشرية أو أجهزة فعلية، لكنها تختبر فضاءً أوسع بكثير من أمثلة ثابتة قليلة، دون إضافة Dependency أو تكلفة أو Network.
