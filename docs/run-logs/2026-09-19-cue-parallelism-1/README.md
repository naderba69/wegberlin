## البيئة (تتكرر كل جلسة وتُكلّف زمنًا)

`node_modules` ومجلد `~/.cache/ms-playwright` و`~/.pwlibs` ليست في لقطة مساحة العمل، فتضيع عند حدّ الجلسة:
‏`npm ci` (‏471 حزمة في 16 ثانية) ثم `npx playwright install chromium` ثم فكّ حزم nspr/nss/atk1.0-0t64/atk-bridge/atspi
(cups2/libxkbcommon0/libasound2/libxdamage1/libavahi-common3/libavahi-client3) من `deb.debian.org/pool` إلى `~/.pwlibs/root`.
عائلة at-spi يجب أن تكون من سطر واحد (‏2.56.2-1+deb13u2 للثلاثة)، إلا ألقى chromium
`undefined symbol: atk_object_get_help_text`. والمبادلة ضرورية للبناء: `sudo fallocate -l 4G /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile`.
