## ما نُفِّذ

- حُوِّل **11 عنصر قرينة** في `b2-19` (كان 11 من 13 = 85%) وأُعيد تأليف **33 مشتتًا ألمانيًا**. الكتابة الوحيدة في
  بيانات الدروس: `scripts/cue-batch.py` ثم `scripts/parallelise-options.py --batch … --write`؛ المفتاح و`correctIndex`
  لم يُمَسّا (11 عنصرًا في ملف واحد كما يطبع الأداة).
- **لا جولة تصحيح هذه المرة**: قُبلت الدفعة من المحاولة الأولى، لأن التأليف سبَقَه فاحصٌ محليّ يحاكي منطق
  `cue-batch.py` حرفيًا (تجريد `.!?` النهائية قبل العدّ، رفض أن يكون المفتاح `max` أو `min` **حتى لو بالتعادل**،
  توسيع ≤25 محسوبًا على العناصر الأربعة، طيّ `ä/ö/ü/ß` قبل مقارنة التكرار). الدرس صار **صفر** عنصر قرينة
  (مقيسًا بـ`scripts/dump-cue-items.ts b2-19` ⇒ صفر سطر).
- **لم يحتج الدرس إلى إصلاح حارس**: بعد إدراج `b2-19` في `PARALLELISED` (**15** درسًا) مرّ
  `tests/unit/mcq-option-parallelism.test.ts` **16/16** من أول تشغيل. العنصران غير القرينيين في الدرس كانا
  سليمَي الطرفين أصلًا — خلافًا لـ`b2-17-m2` (عند v148) و`b1-12-m5` (عند v144) اللذين كشفهما الحارس.
- الكاش رُفع إلى `dwnb-full-pack-v149` (staging/previous على v148) في **سبعة** ملفات، لا ستة:
  `public/sw.js` · `scripts/verify-continuation-handoff.mjs` · `tests/e2e/critical-flows.spec.ts` ·
  `tests/unit/offline-pack-controls.test.ts` · `tests/unit/offline-recovery-partial-export.test.ts` ·
  `tests/unit/today-offline-readiness.test.ts` · **و**`tests/unit/offline-curriculum-rollback.test.ts`
  (هذا السابع لا يذكر `full-pack-v148` إطلاقًا — يذكر `…-previous-v147` فقط؛ أول grep بنمط خاطئ
  (`dwnb-staging-pack-*`) فوّته فأفشل الحزمة باختبار واحد حتى أُصلح).

## عطل بيئة جديد: لا سوابل ⇒ البناء تعثّر عند فحص الأنواع

`swapon /home/user/.swapfile` رُفض هذه الجلسة (`Operation not permitted`)، والذاكرة 1,984 ميغابايت بلا سوابل.
شُغّل `npm run build` بـ`NODE_OPTIONS=--max-old-space-size=1200` فنجحت webpack («Compiled successfully in 22.4s»)
ثم وقف **تسع دقائق** عند «Running TypeScript» مع 15 ميغابايت متاحة للنظام كله، فقُتل التشغيل. الإجراء الذي نجح ولا
يغيّر أي ضبط في المستودع: تشغيل ما يستدعيه Next حرفيًا لتدفئة الذاكرة الزيادة —

```
node --max-old-space-size=900 node_modules/typescript/bin/tsc --project tsconfig.json --noEmit \
  --declarationMap false --emitDeclarationOnly false --tsBuildInfoFile .next/cache/.tsbuildinfo
```

(24 ثانية، خروج 0؛ `incremental: true` في `tsconfig.json` يجعل الناتج قابلًا لإعادة الاستخدام)، ثم البناء بسقف
900 ميغابايت ⇒ خروج 0. لا يُعطَّل فحص الأنواع ولا يُعدَّل `next.config`.
