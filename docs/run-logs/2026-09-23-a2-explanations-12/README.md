## ثلاث ملاحظات منهجية

1. **الشرح يُقتبس من المادة المعروضة لا من الذاكرة.** كلُّ «…» في النصوص الجديدة موجودٌ حرفيًّا في خيارات البند أو جذعه أو درسِه (قراءة/تسجيل)، ولهذا بقي فحصُ الاقتباسات على 0 خطأ بعد الدفعة، ولم تُضَف أيُّ ملاحظةٍ جديدة.
2. **المؤشّر لا يُجمَّل.** التطبيق لا يلمس إلا `explanationAr`؛ لذلك لم تتحرّك القرينة (`39.28%`) ولا مزيجُ المفتاح (`25.92/23.84/24.4/25.84`) ولا عدّاداتُ المعجم (`4,874/1,257`)؛ والحراساتُ الثلاث على الأطوال والصياغة الموضعية رفضت **24 طولًا + 4 صياغات** في المحاولة الأولى فعُدِّلت النصوص قبل الكتابة، لا بعدها.
3. **البوابة تبقى حمراء بشرعية.** `lesson:quality:audit` يخرج **1** بملاحظتين معروفتين (الإنتاجية أحادية السلسلة 87.3% مقابل 25%، ووسيط الشرح 28 مقابل 60)؛ وهذه الدفعة تُقرّب الثانيةَ ولا تلمس الأولى — والتفاصيل في `DECISIONS.md` (ADR-084) و`P1_AUDIT.md` (‏P1-397 · P1-398).
