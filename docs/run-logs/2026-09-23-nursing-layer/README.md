## 2) كيف تُقاس القواعد الثلاث بدل أن تُوعَد

1. **لا قاعدة نحوية جديدة:** كل وحدة تُسمّي كتل القاعدة التي تعيد استعمالها في درسها (`reusedTheoryIds`)، والمدقّق يفشل عند مرجع لا يُحلّ. مثال: `a2-05-nurse` تعيد استعمال `a2-05-t3` (التنبيه دون تصعيد)، و`b2-10-nurse` تعيد `b2-10-t1/t2`.
2. **لا معرفة سريرية مطلوبة للجواب:** المقبول دائمًا فعلٌ لغوي (إعادة قول، تأكيد، سؤال، توثيق)، والمدقّق يرفض خيارًا صحيحًا يقرأ كتعليمة على جسمٍ أو جرعة (`Tablette/Tropfen/Spritze/Dosierung`)، **ويُلزِم خيار تخمين** حتى يكون الإفشالُ من البيئة لا من قائمة قواعد محفوظة.
3. **الطبقة طفيلية:** قياسٌ بنيوي (لا تصريح) بأن لا ملفًّا حاكمًا يذكرها؛ وحذفُ `src/data/nursing-layer-registry.ts` يُسقط اللوحةَ وحدها ويبقي مسار B2 العام كاملًا، لأن البوابات والامتحانات والإتقان لا تستوردها أصلًا (اختبار الوحدة يثبّت قائمة المستوردين الثلاثة داخل `src/`).
