# سجل تشغيل: حزمة برومبتات للمساعد الخارجي (P2-225)

- **التاريخ:** 2026-09-27 · **الوحدة:** `external-prompt-pack-v1` · **الموقع:** `/tutor` (لوحة «برومبتات جاهزة لمساعد خارجي مجاني»)

## القياسات (من الاختبارات والمسبار لا من الوعود)

| القياس | القيمة |
|---|---|
| بطاقات مؤلَّفة | **6** (كتابة · حوار · قاعدة · مفردات · سمع/تكرار · مهمة امتحانية) |
| قيود إلزامية في كل نصّ | **4** (لغة · لا درجة/لا ادّعاء رسمي · لا اختراع صيغة · حدّ المستوى) |
| سقف البطاقة | **1,200 حرفًا** (مقيس من الواجهة في المتصفح) |
| سقف الحزمة | **6,000 حرفًا** · السياق الإضافي **600 حرفًا** |
| رفض السرّ | `sk-…` · `token=` · `dwnb-ai-key` · سلاسل ≥32/≥40 ⇒ لا إدراج + نسخ متوقف |
| شبكة/تخزين | **صفر**: لا `fetch` ولا `XMLHttpRequest` ولا `localStorage`/`sessionStorage` ولا قراءة مفتاح (فحص مصدر في الوحدة) |
| وحدات | `tests/unit/external-prompt-pack.test.ts` **9/9** |
| متصفح | اختبار واحد على `/tutor` (سطح مكتب + جوال) |

## ما يجري فعلًا في المتصفح

1. `/tutor` يعرض السياق الحقيقي: المستوى وامتحان الهدف والدرس المفتوح (أو «لا درس مفتوح الآن»).
2. كتابة `sk-proj-…` في «سياق إضافي» ⇒ تحذير ظاهر، **لا يُدرج في أي نصّ**، والنسخ يرفض برسالة «رُفض النسخ: … مفتاحًا أو سرًّا».
3. كتابة سياق سليم ⇒ يُدرج حرفيًا في النصوص، والنسخ يعمل، ورسالة الحالة تقول أي مسار سلك: «نُسخ إلى الحافظة» أو «حُدِّد النصّ كاملًا — انسخه بـCtrl+C».

## حدود صادقة

- ما تلصقه في المساعد الخارجي يخرج من جهازك بفعلتك أنت؛ التطبيق لا يرسل شيئًا ولا يقرأ ردّ المساعد.
- جودة ردّ المساعد المجاني غير مضمونة، وليست تصحيحًا رسميًا ولا درجة؛ اللوحة تقول هذا بنصّ ثابت.
- لا قياس لجودة ردود المساعدين الخارجيين في هذه الدورة (ذلك يحتاج مراجعة بشرية مستقلة ولم يُدَّع).
