# سجلّ تشغيل — ترقية الحزمة على دفعات (v184)

**الغرض:** تشخيص تجمّد تثبيت الحزمة الكاملة (A1–B2 مع الصوت) في اختبار E2E، ثم إصلاحه بنقلِ المحتوى
على دفعاتٍ تقودها الصفحة. المرجع: `docs/adr/ADR-095-page-driven-chunked-pack-promotion.md`.

## كيف أُجري القياس
على مضيف هادئ (لا حمل)، عبر Chromium في Playwright مقابل نسخة إنتاجية على المنفذ 3100:

1. تثبيت حزمة A1 أولًا (للتحقّق من المسار السريع)، ثم حزمة `A1–B2 komplett` مع الصوت الاختياري.
2. مراقبة نصّ بطاقة الحزمة كل 10 ثوانٍ، مع عدّاد داخلي في العامل (عدد العمليات التي بدأت/انتهت،
   وأعمار العمليات المعلّقة) يُقرأ عبر **نبض رسالة** يحمل بصمة إقلاع العامل `bootId`.
3. عند التجمّد: قراءة حالة التسجيل، ثم تنفيذ نسخٍ تجريبي من **حدثٍ جديد** لداخل العامل نفسه.

## النتائج المقيسة (قبل الإصلاح)
| المشاهدة | القيمة |
| --- | --- |
| مدخلات التحضير | 698 مدخلًا (منها 275 ملف صوت في العيّنة) |
| زمن العملية الواحدة | match 2 مللي ثانية · put 17–22 مللي ثانية |
| ما نُقل قبل التجمّد | 580 / 582 / 600 / 612 / 625 / 650 / 690 مدخلًا في ~20 ثانية، ثم توقّف |
| العمليات المعلّقة | 24 (كامل التزامن) · أقدمها 215 ثانية |
| `deadlineFired` بعد 215 ثانية | **0** (مهلة 45 ثانية لم تُطلق) |
| نبض العامل | يعمل: نفس `bootId`، ومؤقّت 5 ثوانٍ (`lastTickAgoS = 1`) |
| نسخ 20 مدخلًا من حدثٍ جديد أثناء التجمّد | **38 مللي ثانية** |
| نسخ 30 مدخلًا من الصفحة أثناء التجمّد | **53 مللي ثانية** |
| أثر المتعلّم | مراقب الصفحة (150 ثانية صمت) يُظهر «توقّف تثبيت الحزمة… أعد المحاولة» وفشل الاختبار عند 360 ثانية |

**الخلاصة:** العامل حيّ والقرص والذاكرة بخير؛ العطب في **حدثٍ واحد طويل** لا تُستكمَل فيه بعض عمليات
Cache API ولا تُطلق مهلاته. لذلك صار النقل دفعاتٍ (25 مدخلًا/رسالة) من الصفحة، بـ 15 ثانية لكل عملية،
وخمس عمليات متزامنة، وإعادة إرسال الدفعة نفسها عند الفشل (النسخ مُتكرِّر بأمان)، وتحقيقِ إتمامٍ
يعدّ المدخلات الناقصة قبل إعلان الاكتمال.

## أثر الإصلاح على السلوك
- التقدّم يُحدَّث كل دفعة (25 مدخلًا) بدل كل 25 مدخلًا في مسارٍ متجمّد محتمل: نسبة البطاقة دقيقة دائمًا.
- فشلُ دفعة لا يُلغي التنزيل: إعادة المحاولة تُكمل الناقص فقط.
- لا تُكتب فهرسة الحزمة إلا بعد التأكّد من وجود كل المدخلات؛ فلا تظهر حزمة «مثبّتة» ناقصة.
- مخبأ «الحزمة السابقة» (للتراجع) يُبنى دفعاتٍ أيضًا، وقبل حذف الحزمة الحيّة.
