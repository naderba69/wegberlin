# سجلّ تشغيل — تقييم قابلية الفهم بمهمةٍ حقيقية (P2-156)

**الغرض:** تنفيذ البند P2-156 (تقييم قابلية الفهم عبر مهمة حقيقية لا قراءة كلمات فقط) وتوثيق المقاسات.
المرجع: `docs/adr/ADR-096-real-task-comprehensibility-check.md`.

## ما بُني
- `src/core/pronunciation/comprehensibility-task.ts` — سياسة `real-task-comprehensibility-check-v1`:
  بنك **8** مهام مُؤلَّفة (A1 2 · A2 2 · B1 2 · B2 2)، إنشاء حكمٍ بتحقّق صارم، انتقاءٌ بالمستوى بسقف
  **3** مهام للجلسة، ملخّصٌ صادق يفصل «حكم مستمعٍ آخر» عن «تقرير ذاتي».
- `src/components/comprehensibility-task-panel.tsx` — واجهة المهمة وسؤال المستمع وورقة الجواب وحفظ الحكم.
- الحالة: حقلٌ واحد جديد `comprehensibilityChecks` في سلة **الأدلة** ⇒ التصنيف **66** حقلًا
  (19 محذوف / **25** أدلة / 12 إعدادات / 10 هوية).

## التحقق
- اختبارات الوحدة: `tests/unit/comprehensibility-task.test.ts` — **11/11**.
- اختبار E2E جديد (سطح مكتب + موبايل) يمرّ بدورةٍ كاملة: بلا اختيارٍ لا حكم، والاختيار المخالف لا
