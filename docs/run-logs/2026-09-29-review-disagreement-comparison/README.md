# سجلّ تشغيل — مقارنة اختيارية بين تقييمين عند عدم اليقين (P2-215)

## ما بُني

- `src/core/writing/review-comparison.ts` — سياسة `review-disagreement-comparison-v1`:
  مقارنة **جنبًا إلى جنب** بين مراجعتين محفوظتين للنسخة نفسها: ما اتفقتا عليه · ما ظهر في واحدة فقط ·
  وما اختلفتا فيه فعلًا (صياغة مختلفة أو ثقة مختلفة) — بلا دمج وبلا تصويت وبلا متوسط وبلا اختيار آلي
  (`side-by-side-only-no-merge-no-score-no-majority-vote-no-auto-pick`)، ووسم `needsHumanReview` يُشعل عند وجود
  خلاف فعلي فقط · زاويتان معلَنتان للرأي الثاني (`coverage` · `style`) · `assertReviewComparisonIntegrity` تعيد
  فحص الأرقام وحدود الادّعاء على أي مقارنة مخزَّنة أو معروضة.
- `src/components/hybrid-writing-review.tsx` — زرّ **اختياري** «اطلب الرأي الثاني بموافقة مستقلة» + اختيار الزاوية،
  وحوار موافقة مستقل يذكر الزاوية وعدد الحروف، ثم كتلة العرض: العدّادات الثلاثة، قوائم الاتفاق والانفراد، والخلافات
  بصيغتين متجاورتين مع تنبيه أن أحداهما ليست «الصحيحة».
- `src/core/ai/client.ts` — الزاوية تمرّ في طلب واحد إضافي **بنفس مسار Gemini BYOK المجاني** (`askGeminiWritingReview`)
  مع حارس `assertAIZeroCost` كما هو؛ لا مزود ثالث ولا بديل مدفوع ولا إرسال تلقائي.
- `src/core/writing/hybrid-review.ts` + `src/types/learning.ts` + `src/core/portability/schema.ts` — حقل
  `comparisonSlot` (`first`/`second`) يمرّ إلى الدليل ويُصدَّر/يُستورد بلا فقد (حقل ضمني اختياري: لا حقل حالة جديد
  ولا تغيير في تصنيف 66 حقلًا).

## المقاسات

| المقياس | القيمة |
| --- | --- |
| زوايا الرأي الثاني | 2 معلَنتان (`coverage` · `style`) |
| إرسالات إضافية | **1 كحدّ أقصى** (`noThirdRequest`)، كلٌّ بموافقة مستقلة جديدة |
| مزودون | 1 (نفس مزود المستخدم المجاني) — 0 مزود مدفوع · 0 بديل تلقائي |
| نوعا الخلاف المعروضان | صياغتان مختلفتان (نص واحد) · ثقتان مختلفتان (صياغة واحدة) |
| عدّادات الواجهة | `agreed` · `onlyFirst` · `onlySecond` · `divergences` + `needsHumanReview` |
| درجة/مستوى/بوابة | 0 (محظورة باختبارات وبـ`assertReviewComparisonIntegrity`) |
| كتابة في الإتقان أو الأدلة | 0 (المقارنة عرضٌ فقط؛ المراجعات تبقى أدلة استشارية بحدّها القديم) |
