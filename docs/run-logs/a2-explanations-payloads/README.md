# حمولات دفعات شروح A2 (العقد 1 → 12) — موادُ إعادة التشغيل والتدقيق

أربعَ عشرةَ حمولة JSON، لكلٍّ منها بندٌ واحد أو ثلاثةٌ أو أربعةٌ وعشرون بندًا، بالشكل نفسه:

```json
{ "a2-01-rq1": { "explanationAr": "…النصّ العربي المكتوب…", "oldLen": 15 } }
```

- `oldLen` **قفلُ تموضعٍ لا رقمٌ توثيقي**: يُطابَق طولُ الشرح الحيّ في `src/data/lessons-a2-module*.ts` قبل الكتابة،
  فإن لم يطابق رُفض البند (`LEN-MISMATCH`) بدل أن تُكتب في منتصف قائمة؛ وهذا ما يجعل إعادةَ التكرار آمنة.
- **`explanationAr` وحده** تلمسه هذه الحمولات: لا `options`، ولا `correctIndex`، ولا `promptDe` — لذلك لا تتحرك
  القرينةُ ولا مزيجُ المفتاح ولا عدادات المعجم، وتتحرّك `content:audit` و`learning:architecture` وحدهما.

## إعادة التشغيل (بالترتيب)

```bash
cd "$(git rev-parse --show-toplevel 2>/dev/null || echo /home/user/der-weg-nach-berlin)"
for f in a2e1 a2e2 a2e3 a2e4 a2e5 a2e5-fix1 a2e6 a2e7 a2e8 a2e9 a2e10 a2e10-fix1 a2e11 a2e12; do
  python3 scripts/apply-explanation-batch.py --level a2 --payload "docs/run-logs/a2-explanations-payloads/$f.json"
done
npm run lesson:quality
npm run content:audit:write && npm run learning:architecture:audit:write
```

- الدفعاتُ المطبَّقة أصلًا تُتجاوَز بهدوء: `SKIP-already-lifted` لكل بند و`wrote 0 field(s)` في آخر السطر
  (قِيست على الشجرة الحالية بعد الدفعة 12 ⇒ 24 × skip لـ`a2e12.json`, والدفعاتُ 10 و11 كذلك).
- `--dry-run` يطبع ما سيُكتب ولا يلمس شيئًا؛ و`--data-root` يوجِّه الكتابة إلى نسخةٍ للفحص.
- بعد كل إعادة تشغيل: قِسْ ولا تُصدّق تقريرًا نجا من التراجع — `reports/*.json` **لا يصلح دليلاً على حالة المستودع**.
